# 编辑道路

道路节点（RoadSpline）沿一条经过控制点的平滑曲线生成路面，可以把地形按道路挖方、填方，并清除路边的草和植被，适合制作越野、拉力等赛道。

---

## 创建道路

- 主菜单选择 `Add → Road`，在地形上点击放置。点在地形上时，道路会挂到这块地形下面。道路需要放在地形下面，路肩贴地和地形贴合都依赖这块地形。
- 新建的道路还没有控制点，选中后点击工具栏中的编辑按钮，进入道路编辑工具后开始摆点。

道路的高度由控制点决定，不跟随地面起伏：先摆出走向，再用"拟合纵断面"和"贴合地形"让路和地面吻合（见下文）。

---

## 道路编辑工具

选中道路，点击工具栏中的编辑按钮，场景视图中会画出中心线、两侧路边和控制点，并打开 `Road` 面板。

**编辑控制点**

| 操作 | 作用 |
|---|---|
| 拖动控制点 | 沿地面移动，保持该点原有的离地高度 |
| Alt + 拖动控制点 | 上下移动该点 |
| 勾选 `Add points` 后点击地面 | 在道路末端添加控制点 |
| Ctrl + 点击地面 | 在道路离点击处最近的位置插入控制点，高度取那里的路面高度 |
| Delete | 删除选中的控制点 |
| Esc | 取消选择，退出添加模式 |

控制点少于两个时，工具自动进入添加模式。所有操作都可以撤销。

**选中控制点的属性**

- `Above ground`：控制点离地面的高度。
- `Width`：该点处的路宽，0 表示使用道路的 `Width` 属性；控制点之间平滑过渡。
- `Bank`：该点处的横向倾角，正值抬高右侧路边，适合做弯道超高。

**路况提示**

面板显示道路总长、最小转弯半径和最大坡度。场景视图中：

- 中心线变红：该段坡度超过 12%。
- 路边变红：弯道太急，内侧路面已被收窄，避免路面折叠。

---

## 拟合纵断面

`Fit profile` 沿中心线每米采样一次地面高度，在约 30 米的范围内平滑，再把坡度限制在 12% 以内，然后据此调整各控制点的高度。只改控制点的高度，不改走向。

建议先拟合纵断面再贴合地形，这样挖方、填方都比较小。

---

## 贴合地形

`Fit terrain` 按道路修整地形，做法和真实修路相同：

- **路基**：路面和两侧各 1 米范围内，地面整平到路面以下约 10 厘米。
- **边坡**：路基以外，地面被限制在挖方坡（默认 1:1，约 45°）和填方坡（默认 1:1.5，约 34°）之间，只有比边坡更陡的地方才会改动。
- **圆滑**：坡脚在 3 米内从平缓过渡到设定坡度，坡顶在约 2 米内过渡到原地面，车辆冲出路面时不会撞上硬折角。
- **草和植被**：清除路面、路肩及其外 0.5 米内的草，再往外 1.5 米逐渐恢复；边坡上按挖填深度减少草量；路边的植被实例被删除。

**反复贴合**

第一次贴合时，道路会记下被改动区域原来的地形（高度、地表纹理权重和草密度），随场景一起保存。之后移动道路再贴合，会先还原原来的地形再重新挖填，旧位置不会留下痕迹。

- `Restore terrain`：还原原来的地形，并丢弃这份记录。
- `Commit terrain`：丢弃这份记录，以当前地形作为原始地形。之后再贴合，就从当前地形开始计算。

> 注意：贴合之后在道路两侧用地形笔刷做的修改，下次贴合时会被原来的地形覆盖。如果想保留这些修改，先 `Commit terrain`。被删除的植被不会随还原恢复，需要时请撤销或重新散布。

---

## 路肩与地形融合

道路两侧各有一条路肩（`ShoulderWidth`，默认 1 米），从路面逐渐过渡到地面：

- **WebGPU 且地形开启了运行时虚拟纹理（RVT）**：路肩从地形的 RVT 读取地表颜色、法线和粗糙度，从路面材质平滑过渡到地表，路边自然融入地面。推荐使用。
- **其他情况**：路肩用抖动透明逐渐淡出，需要开启 TAA 才显得平滑。

在地形属性中勾选 `RuntimeVirtualTexture` 即可开启 RVT。`ShoulderMaterial` 属性留空时，引擎按上述规则自动选择；指定材质时以指定的为准。

---

## 道路属性

| 属性 | 说明 |
|---|---|
| `Points` | 控制点列表，可以在属性面板中直接编辑 |
| `Closed` | 首尾相连成环形赛道（至少 3 个控制点） |
| `Width` | 默认路宽（米） |
| `ShoulderWidth` | 每侧路肩宽度（米），0 表示没有路肩 |
| `Material` | 路面材质，留空时使用灰色默认材质 |
| `ShoulderMaterial` | 路肩材质，一般留空 |
| `UVTileLength` / `UVTileWidth` | 纹理沿路、横向每重复一次对应的米数，通常设为贴图的实物尺寸 |
| `SampleSpacing` | 网格截面间距（米） |
| `ChunkLength` | 分块长度（米），影响裁剪粒度 |
| `SurfaceTag` | 路面类型名称，供游戏脚本区分不同的路（如 gravel、asphalt） |
| `Collision` / `Friction` | 是否生成静态碰撞体及其摩擦系数 |
| `CastShadow` | 是否投射阴影 |

路面纹理沿道路方向铺设，材质的贴图寻址方式需要设为 `repeat`。

---

## 在脚本中使用道路

`RoadSpline` 提供运行时查询，便于实现计时、检查点和重生：

- `length`：道路全长。
- `sampleAt(s, frame)`：距起点 `s` 米处的位置、方向、路宽和倾角（世界空间）。
- `project(position, out)`：离某个世界坐标最近的中心线点，返回沿路距离 `s` 和横向偏移。
- `ownsNode(node)`：判断一个节点是否属于这条道路。

车轮使用自身的抓地参数（`Wheel.frictionSlip`），不读取碰撞体的摩擦系数。如果要让路面和野地抓地不同，可以在脚本中根据 `wheel.groundNode` 判断车轮是否在路上（`road.ownsNode(wheel.groundNode)`），再按 `surfaceTag` 设置各车轮的 `frictionSlip`。
