# 编辑器界面

**界面组成**（从上到下）：
- **主菜单**：顶部菜单栏，包含所有功能入口
- **工具栏**：快捷操作按钮，提供常用工具
- **工作区**：主要的编辑操作区域
- **状态栏**（底部）：状态信息显示

工作区主要分为四大区域：

| 区域 | 功能说明 |
|------|-----------|
| **Scene Hierarchy**（左） | 显示场景层级结构 |
| **Viewport**（中） | 3D 视图与编辑操作 |
| **Inspector**（右） | 属性编辑；底部的 Scripts 区用于挂载脚本 |
| **Content Browser / Log View**（下） | 资源文件管理与日志查看；桌面版另有 **Assistant** 标签页 |

插件可以在左、右、下三个区域添加自己的面板。

## 视口操作

| 操作 | 作用 |
|------|------|
| 右键拖动 | 原地转动视角 |
| 按住右键 + `W` `A` `S` `D` | 前后左右飞行 |
| 按住右键 + `Q` / `E` | 下降 / 上升 |
| `Alt` + 左键拖动 | 绕视图中心环绕 |
| `Alt` + 中键拖动 | 平移视图 |
| `Alt` + 右键拖动 | 推近 / 拉远 |
| 滚轮 | 推近 / 拉远；按住 `Ctrl` 加快 10 倍，按住 `Shift` 减慢到 0.1 倍 |

## 快捷键

| 快捷键 | 作用 |
|------|------|
| `Q` | 选择模式 |
| `W` | 移动模式 |
| `E` | 旋转模式 |
| `R` | 缩放模式 |
| `F` | 视角定位到选中对象 |
| `Delete` | 删除选中的节点 |
| `Ctrl + D` | 复制当前焦点所在的对象：场景节点、资产或蓝图节点 |
| `Ctrl + C` / `Ctrl + V` | 复制 / 粘贴 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 / 重做 |
| `Ctrl + N` | 新建场景 |
| `Ctrl + O` | 打开场景 |
| `Ctrl + S` | 保存场景 |
| `Ctrl + Alt + S` | 场景另存为 |
| `F2` | 重命名选中的资产 |
| `F12` | 打开开发者工具（仅桌面版） |
