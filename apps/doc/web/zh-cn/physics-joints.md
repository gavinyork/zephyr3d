# 关节

关节把两个刚体（或一个刚体和世界）连起来，只允许特定的相对运动：门绕门轴转、抽屉沿导轨滑、链条节节相连、吊灯挂在绳子上。

## 关节放在哪、连接谁

`Joint` 组件挂在任意节点上，**这个节点就是关节的坐标系**：

- **支点**是节点原点，可以用 `anchor`（节点局部空间）再偏移；
- **轴**是节点局部的 `axis`，默认 Y，用于铰链和滑轨。

所以通常给关节单独建一个子节点，把它摆到门框边上、转到正确的朝向。在编辑器里用移动、旋转工具直接调整，不用手算坐标：

<<< @/../src/tut-79/main.js#hinge

两端：

- **本体**：关节节点上或其祖先上最近的 `RigidBody`。上例的关节节点是门的子节点，本体就是门。
- **另一端**：`connectedBody` 指向另一个节点（取它或它祖先上最近的刚体）。留空表示连到世界，即固定在关节创建时的世界位置。`connectedBody` 按节点的持久 ID 保存，引用的节点晚于关节加入场景也能连上。

关节在创建时记下两端的相对姿态，**此时的角度就是 0**。之后两端被移动也不会重新对齐，这是正确的物理语义；只有改了关节属性、或任一端的刚体被重建时才重新计算。

## 类型

`Joint.type`：

| 类型 | 允许的运动 | 例子 |
| --- | --- | --- |
| `fixed` | 无，两者焊死 | 把两个物体粘成一个、可拆卸的部件 |
| `hinge` | 绕轴转 | 门、轮子、杠杆 |
| `slider` | 沿轴滑 | 抽屉、活塞、电梯导轨 |
| `ball` | 绕支点任意转 | 链条、布娃娃的肩膀 |
| `rope` | 距离不超过 `length`，可以靠近 | 绳子、锁链 |
| `spring` | 在 `length` 附近弹性拉伸 | 弹簧、悬挂 |

## 限位

- `hinge`：`limitsEnabled` 打开后，角度限制在 `lowerLimit`～`upperLimit`（度）之间。
- `slider`：同样的属性，单位是米。
- `ball`：`swingLimit` 限制偏离轴的角度，`twistLimit` 限制绕轴的扭转，都是每个方向的度数。这是逐轴的近似，不是精确的圆锥。

运行时可以读当前值：`joint.angle`（铰链，度）、`joint.position`（滑轨，米）。

## 马达

铰链和滑轨可以由马达驱动，`motorMode`：

<<< @/../src/tut-79/main.js#motor

| 模式 | `motorTarget` 含义 | 用途 |
| --- | --- | --- |
| `off` | — | 自由转动（默认） |
| `velocity` | 目标速度：度/秒或米/秒 | 风扇、传送带、自动门 |
| `position` | 目标角度或位置 | 弹回原位的门、伺服机构 |

- `motorStiffness`：位置模式下拉向目标的力度；`motorDamping`：抑制过冲，速度模式下决定多快达到目标速度。
- `motorMaxForce`：马达最多用多大的力（力矩），0 表示不限。设一个上限，门被挡住时马达会"使不上劲"，而不是把挡路的东西推飞。

## 限制与排错

- 不支持按受力断开关节：Rapier 的 JS 接口读不到关节受力。需要"拉断"时，可以在脚本里比较两端的距离或速度，自己 `removeComponent`。
- 没有六自由度的通用关节；上面六种覆盖了常见需求。
- 两端都不是动态刚体时关节照常创建，但没有效果。
- `connectedBody` 指向的节点不存在、或两端解析到同一个刚体时不创建关节，原因在 `joint.error` 里。
- 长链条（几十节以上）可能被拉长或抖动：提高场景设置的步频（`fixedTimeStep` 设小）能改善。
