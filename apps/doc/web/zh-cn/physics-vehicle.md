# 载具

`Vehicle` 把一个刚体变成汽车、卡车这类带轮子的载具：油门、刹车、方向盘，加上能看到起伏的四轮悬挂。它封装了 Rapier 的射线悬挂载具（移植自 Bullet 的 `btRaycastVehicle`），这也是游戏里做车最常见的方式。

## 坐标约定

- 上方向是车身节点的 +Y。
- 车头方向由 `vehicle.forward` 决定：`'+z'`（默认，glTF 模型的朝向）、`'-z'`、`'+x'`、`'-x'`。
- 车轴沿车身的横向。所以轮子模型的初始朝向只需要"看起来对"：上例的圆柱默认竖着，旋转 90° 躺倒后，它的轴就是车轴。

## 驾驶

| 输入 | 范围 | 作用 |
| --- | --- | --- |
| `throttle` | -1～1 | 油门；负值倒车 |
| `brake` | 0～1 | 脚刹 |
| `handbrake` | 布尔 | 手刹 |
| `steering` | -1～1 | 方向盘；**正值左转** |

输入一直保持到下次修改，每个物理步都会生效。`vehicle.speed` 是沿车头方向的速度（m/s，倒车为负）。

输入怎么分到各个轮子，由轮子上的系数决定：

| 车辆属性 | 轮子系数 | 每个轮子得到的 |
| --- | --- | --- |
| `maxEngineForce`（N） | `drive` | 油门 × 最大驱动力 × `drive` |
| `maxBrakeForce`（N） | `brake` | 刹车 × 最大刹车力 × `brake` |
| `maxHandbrakeForce`（N） | `handbrake` | 手刹力 × `handbrake` |
| `maxSteerAngle`（度） | `steer` | 方向盘 × 最大转角 × `steer` |

驱动方式就是改 `drive`：后驱时两个后轮各 0.5，前驱时两个前轮各 0.5，四驱时各 0.25。`steer` 设为 -1 就是反向转动的后轮转向。

<<< @/../src/tut-81/main.js#drive

需要自己做差速、牵引力控制时，可以直接给单个轮子加输入：`wheel.engineForce`（N）、`wheel.brakeForce`（N）、`wheel.steerAngle`（度），它们叠加在按系数分到的值上。

- **踩着油门时刹车不起作用**：Rapier 在轮子有驱动力时忽略刹车。示例里的"按住后退键先刹车、停下后倒车"就是为此。
- **没有滚动阻力**：松开油门不刹车，车会一直滑行。给车身 `RigidBody.linearDamping` 一个小值（0.1 左右）来模拟。

## 调悬挂和轮胎

`Wheel` 的属性：

| 属性 | 默认 | 作用 |
| --- | --- | --- |
| `radius` | 0.4 | 轮子半径 |
| `suspensionRestLength` | 0.3 | 悬挂自然长度 |
| `suspensionStiffness` | 30 | 弹簧刚度，**按每千克车重计**：轻车和重车用同样的值手感相同 |
| `suspensionCompression` | 2.2 | 压缩时的阻尼：越大，过坑越"硬" |
| `suspensionRelaxation` | 3.3 | 回弹时的阻尼：越大，车身越快停止弹跳 |
| `maxSuspensionTravel` | 0.3 | 轮子能离开静止位置多远 |
| `maxSuspensionForce` | 1000000 | 悬挂最大推力（N）；设得太小，重车会塌到地上 |
| `frictionSlip` | 1.5 | 抓地力，类似摩擦系数：越小越容易打滑、甩尾 |
| `sideFriction` | 1 | 侧向抓地的缩放：小于 1 时过弯容易滑出 |

- **静止下沉量**：四个轮子平均分担时，悬挂压缩 9.81 / (4 × 刚度) 米。默认 30 时约 8 厘米。刚度太小，车身会沉到底、过坑时托底。
- **阻尼**：Bullet 给出的经验值是阻尼 = k × 2√刚度，k 取 0.1～0.3，压缩取小、回弹取大。默认值就是这样来的。阻尼太小，车会一直上下弹跳；太大则像没有悬挂。
- **重心**：车身绕节点原点转动（见 [刚体物理](zh-cn/physics-intro.md)）。原点越高越容易侧翻；把车身节点的原点放低、用碰撞体的 `offset` 把形状抬上去，车会更稳。

## 局限

- **轮子是一条射线**：比轮子窄的坑会掉进去，台阶边缘会"看到"得晚。
- **轮子本身不碰撞**：车轮蹭到墙不会被挡，挡住的是车身碰撞体。所以车身碰撞体要包住车的外形。
- 没有发动机扭矩曲线、变速箱、差速器、防倾杆、空气阻力。需要时在脚本的固定步里按速度计算 `throttle` 或直接施力，例如空气阻力：

```js
world.on('fixedupdate', () => {
  const v = body.getLinearVelocity();
  body.applyForce(Vector3.scale(v, -0.4 * v.magnitude)); // 阻力随速度平方增长
});
```

- 车身睡眠后，没有输入时载具不再更新；设置任何输入都会唤醒它。
- 轮子射线只在 `vehicle.layer` 能碰撞的层上找地面，不检测触发器。
- `vehicle.error` / `wheel.error` 说明没能建立的原因：车身节点上没有动态刚体、车身下面没有轮子、轮子不在任何载具下面。
