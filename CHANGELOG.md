# Changelog

All notable changes to Zephyr3D are documented in this file. Per-package changelogs live in each
`libs/*/CHANGELOG.md` and are generated by Rush; this file gives the project-wide view.

## 1.0.0

The first stable release. The core API now follows semver — breaking changes will come with a major
version bump and a documented deprecation path.

### Highlights

- **Probe-based global illumination** (WebGPU) — DDGI probe clipmap traced through a global SDF
  composed from mesh SDFs and terrain, lit by sun, local lights, rect lights and sky.
- **Volumetric clouds** (WebGPU) — coverage-map and noise shaping with an octahedral sky cache,
  Nubis-style cloud shape modelling, generated or imported noise volumes.
- **Physics integration** — Rapier-backed rigid bodies, colliders, joints, character controllers
  and vehicles saved with scenes; gravity, step rate and collision layers as scene settings.
- **Hair rendering** — Kajiya-Kay and Marschner shading models, GPU strand expansion, deep opacity
  map shadows, TressFX-derived physics simulation, compute-shader wind.
- **Mesh LOD** — discrete LOD chains with runtime mesh simplification, GPU instance-level selection
  for BatchGroup, and debug LOD colouring views.
- **KTX2 / compressed assets** — KTX2 textures (ETC2, ASTC, BC), Draco and meshopt geometry
  compression, binary `.zmsh` primitives, and a pipeline cache for ahead-of-time compilation.
- **Foliage system** — PCG-style density-mask scattering in a worker, placement on any surface,
  per-chunk static colliders, terrain height queries.
- **Shore waves** — trochoid wave trains that shoal, break and swash, driven by a cascaded
  waterline field built from terrain or the scene SDF.

### Rendering

- Reworked water: FFT cascades split into non-overlapping bands, slopes filtered by mip footprint,
  refraction blur, Crest-style foam shading, persistent advected foam field, interaction waves.
- Reworked skin SSS: per-channel energy-conserving diffusion, Burley normalised sampling, shadow
  tint and scatter colour, per-pixel profile lookup from a shared parameter table.
- Eye material with corneal refraction, limbal ring, pupil dilation and socket occlusion.
- Rect area lights with LTC normalisation, cube-map PCSS shadows and transmission.
- Screen-space contact shadows (UE5-style).
- Instanced skinning with GPU animation banks and GPU culling of BatchGroup instances.
- Procedural blade grass with scene wind, clump noise, LOD and screen-space shadow projection.
- Sparse / runtime virtual texturing for terrain with anti-tiling.
- Reverse-Z depth for better far-distance precision.
- Pipeline cache: record and precompile pipelines ahead of time from a `pipeline-cache.json`.
- LoadingScreen protocol driven by LoadingProgress for application startup.

### Editor

- Built-in splash / loading screen with engine logo and per-stage progress.
- Example scenes: Cornell Box, Buildings, Terrain.
- MCP server for AI agents and external tools (desktop build).
- Material blueprints, terrain sculpting, animation editing and a plugin API.

### Breaking changes

- **WebGL1 dropped.** `'webgl'` is now a deprecated alias for WebGL2.
- Camera controller event types are no longer generic; the per-type pointer event interfaces
  (`IControllerPointerDownEvent` etc.) are removed.
- Water legacy ramp medium mode (`mediumMode`, `scatterRampTexture`, `absorptionRampTexture`) and
  shoreline foam band properties (`shoreFoam*`) are removed.
- `SubsurfaceScatteringMaterial.sss` is deprecated in favour of `SSSMaterial`.
- `SpringModifier` is renamed to `JointDynamicsModifier`.
- `Node >= 20` is now required (was >= 16.18).

### Infrastructure

- All packages bumped from 0.x to 1.0.0.
- Build-time dependencies (`@rollup/plugin-commonjs`, `rollup-plugin-import-css`, `@types/node`)
  moved from `dependencies` to `devDependencies` across all published packages.
- `engines.node` bumped to `>=20.0.0` across all packages to match Rush.
- Visual regression tests run in CI on SwiftShader with digest-based baselines.
- LICENSE updated to 2024-2025.
